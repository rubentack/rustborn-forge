# Rustborn Forge

Releases of **Rustborn Forge**, the hand-in tool for students working on Rustborn assignments at
Howest DAE. This repository only holds the releases; there's no source code here.

## Install

Download **RustbornForge-Setup.exe** from the [latest release](https://github.com/rubentack/rustborn-forge/releases/latest)
and run it. No admin rights are needed. Forge isn't code-signed, so Windows may show *Windows protected
your PC* the first time: click **More info → Run anyway**.

Forge keeps itself up to date: when there's a new version it shows a banner with **Update now**.

The `assignments` release holds the assignments Forge reads; it isn't a Forge version.
